Technology Stack

These are the technologies we use to build the app

Frontend Technologies

React Native

Our mobile app is built with React Native and JavaScript, enabling cross-platform development with native performance. This allows us to maintain a single codebase for both iOS and Android platforms.

Context API

React's Context API handles our state management needs, providing a clean and efficient way to share data between components without prop drilling.

Backend Technologies

FastAPI

FastAPI powers our backend with its high performance, automatic API documentation, and modern Python features for rapid development.

Database Technologies

SQL

Our primary database is SQL, chosen for its reliability, robust feature set, and excellent support for complex queries and data relationships.

Additional Technologies

Stripe

Powers our payment processing with secure transactions, multiple payment methods support,multiple countries compatibility, and seamless checkout experience.

Azure DevOps

Manages our CI/CD pipeline, version control, and project management, ensuring smooth development workflow and automated deployments.
